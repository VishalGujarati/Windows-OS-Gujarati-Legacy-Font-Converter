# Gujarati Legacy Font Converter

A free, offline desktop converter for historical Gujarati legacy-font text.

## Supported input families

- Hari / Harikrishna
- LMG Arun / Lohit BKMAN

## Output

Unicode Gujarati, with document conversion designed to preserve the original
DOCX/ODT structure and formatting as far as the file format permits.

DOCX output prefers the `Lohit Gujarati` Unicode font when available, followed
by other common Gujarati Unicode fonts.

## Developed by

VishalGujarati

Developed with the help of AI tools, open-source technology, public
documentation, and online resources.

This project is intended to be free software for users who need to recover
and modernize old Gujarati documents.

## Offline

Conversion is performed locally. The converter does not require an online
conversion API for its core text/document conversion.
